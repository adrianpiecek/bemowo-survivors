# Bemowo Survivors

Memowa gra w stylu Vampire Survivors o Bartku z Bemowa. Jedna runda trwa 10 minut: przeżyj hordę wariantów Bartka, zbieraj kryształy, wybieraj ulepszenia, a między rundami wydawaj białko w siłowni.

## Uruchamianie

```
python -m http.server 8000
```

Potem otwórz `http://localhost:8000`. Plik `index.html` otwarty prosto z dysku nie zadziała (moduły ES).

## Sterowanie

- Ruch: WASD albo strzałki. Na telefonie joystick pojawia się tam, gdzie dotkniesz ekranu.
- Strzelanie jest automatyczne.
- Czołg: Spacja, gdy pasek jest pełny (na telefonie dotknij paska).
- Karty przy level upie: kliknięcie albo klawisze 1-3.
- M: wycisza i włącza dźwięk (zapamiętane po odświeżeniu).
